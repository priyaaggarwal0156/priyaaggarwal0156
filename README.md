## 🚀 Featured Projects

**🌍 Smart Environmental Safety Monitor** &nbsp;`ESP32` `Blynk IoT` `7 Sensors`
> Sensor-fusion firmware processing 7 live streams — gas, air quality, temp, humidity, water, rain, motion. Weighted **Safe / Warning / Danger** risk engine with real-time mobile alerts and asynchronous Wi-Fi interrupt prioritization.

---

**🛡️ Shield-X Pro — Emergency Response Ecosystem** &nbsp;`ESP32` `Cloud` `Wearable`
> Wearable IoT safety system with **voice + touch SOS triggering**, multi-sensor threat detection, evidence logging, and instant cloud-based emergency notifications. Built to replace phone-dependent systems.

---

**📡 Dual-Interface Smart Radar System** &nbsp;`Arduino` `Ultrasonic` `Servo` `p5.js`
> 180° PWM servo scan + ultrasonic ToF distance measurement + live UART streaming to an interactive **p5.js radar dashboard**. Non-blocking multi-peripheral firmware — servo, OLED, sensor running in parallel.

---

**🤖 Black Line Follower Robot** &nbsp;`Arduino` `IR Sensors` `L298N Motor Driver`
> Autonomous differential-drive robot with real-time **closed-loop PWM motor control** — adjusts drive motors based on IR sensor deviation to stay locked on path.

---

**🏠 Smart Home Automation** &nbsp;`ESP32` `Relay` `Blynk IoT` &nbsp; 🏆 **1st Place — IoT Enigma Competition**
> Full IoT home automation — IR motion detection, relay-based appliance control, Blynk app + Gmail dual alerts. **Designed, wired, and deployed in under 60 minutes** during competition. Won 1st place.

---

**🎓 Multi-Factor Smart Attendance System** &nbsp;`Embedded C` `I2C` `5 Sensors`
> Zero-proxy hardware validation using **Hall Effect + PIR + Piezo + Capacitive Touch + Sound** sensors. I2C OLED display + matrix keypad. No software tricks — pure hardware authentication.

---

**🧠 Digital IC Design Suite — 12 Circuits** &nbsp;`Verilog HDL` `ModelSim`
> ALU · BCD Adder · 4:1 MUX · D Flip-Flop · Universal Shift Register · Up-Counter · CMOS Inverter · NMOS NOR. All verified with **rigorous ModelSim testbenches — 100% truth-table accuracy**.
